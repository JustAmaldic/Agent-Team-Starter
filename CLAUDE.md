# Claude Code instructions

Follow `AGENTS.md` and `POLICY.md` exactly. When reviewing Codex work, read the actual diff and provide concrete actionable findings. Never modify files in review-only mode. Store review artifacts through the ATS coordinator.

## Git collaboration rule

For every ATS code or policy change: create a dedicated feature branch from main, commit only on that branch, and open a pull request for review. Never push changes directly to main or merge your own pull request automatically. Follow POLICY.md and retain review feedback and comments in ATS data where applicable.
